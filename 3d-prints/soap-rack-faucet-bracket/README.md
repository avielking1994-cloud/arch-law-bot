# תושבת לברז עבור מתקן סבון/ספוג (הדפסת תלת־ממד)

תושבת שמתלבשת על צינור הברז (ברבור) ומחזיקה מלמטה את מוט המתקן, כך שהמתקן
לא נופל כלפי מטה. הזרוע עולה בזווית של 15° לכיוון הקיר, ולכן כל ניסיון של
המתקן לרדת דוחף את קצה הזרוע חזק יותר אל הקיר (טריז).

## קבצים

| קובץ | מה זה |
|---|---|
| `bracket_L110.stl` | הגרסה הראשית: מרחק 110 מ"מ ממרכז צינור הברז עד הקיר |
| `bracket_L100.stl`, `bracket_L120.stl` | אותה תושבת עם זרוע קצרה/ארוכה יותר, למקרה שהמדידה לא מדויקת |
| `bracket.py` | הסקריפט שמייצר את ה־STL. כל המידות פרמטריות בראש הקובץ |
| `preview.png` | תצוגה מקדימה |

## הנחות (אם משהו שונה – לשנות ב־`bracket.py`)

* קוטר צינור הברז: 25 מ"מ (`PIPE_D`), עם מרווח 0.6 מ"מ.
* 11 ס"מ = המרחק ממרכז הצינור עד הקיר (`ARM_L`). אם נמדד מדופן הצינור, `ARM_L = 122`.
* עובי חוט המתקן: 5 מ"מ (`WIRE_D`), החריץ ברוחב 7.5 מ"מ.
* זווית עלייה של הזרוע: 15° (`ANGLE`).

## הרכבה

1. פותחים את הטבעת (פתח 23 מ"מ) ולוחצים אותה על החלק הישר של צינור הברז, כשהזרוע פונה לקיר.
2. מהדקים עם בורג M4 ואום (יש כיס לאום בצד אחד של האוזניים).
3. מניחים את המוט התחתון של המתקן בחריץ שבקצה הזרוע; לוחית הקצה נשענת על הקיר.
4. אם הזרוע ארוכה במעט מהמרחק – מסובבים את התושבת קצת הצידה על הצינור עד שהלוחית נוגעת בקיר.
   אם קצרה – להשתמש ב־`bracket_L120.stl` או להגדיל `ARM_L`.

## הדפסה

* ה־STL כבר בכיוון הדפסה: הזרוע שטוחה על המשטח, ללא צורך בתמיכות.
* PETG מומלץ (עמיד ברטיבות ובכיפוף), PLA גם בסדר.
* 4 קירות (perimeters), מילוי 30–40%, גובה שכבה 0.2 מ"מ.

## יצירה מחדש

```bash
pip install manifold3d numpy
python3 bracket.py        # bracket_L110.stl
python3 bracket.py 125    # אורך זרוע אחר
```
